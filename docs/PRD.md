# 产品需求文档 (PRD)

## 项目概述

一个高性能、可维护的个人博客系统，用于分享技术文章和个人见解。

## 目标用户

- **主要用户**：技术社区读者、潜在雇主
- **次要用户**：开发者、同行博主

## 核心页面

| 页面 | 路径 | 描述 |
|------|------|------|
| 首页 | `/` | 文章列表、分类入口、热门文章 |
| 文章详情 | `/[slug]` | 正文、目录、点赞、社交分享图 |
| 分类 | `/categories`、`/categories/[slug]` | 分类列表与分类下文章 |
| 关于 | `/about` | 个人介绍、联系方式 |
| 归档 | `/archive` | 按时间/分类归档（规划中，未实现） |

## 功能清单

### MVP (第一期)

- [x] Markdown 文章渲染（marked + shiki 高亮、mermaid、code group）
- [ ] 文章列表分页（目前首页全量展示）
- [x] 文章分类（固定分类表；未做自由标签）
- [x] 响应式布局
- [x] SEO 基础（title、description、sitemap、robots、RSS）
- [x] 深色模式

### 后续迭代

- [x] 搜索功能（客户端弹窗，标题/摘要/分类子串匹配）
- [x] 文章目录 (Table of Contents，桌面侧栏 + 移动端浮层)
- [x] 国际化 (i18n，cookie 切换中英 UI；文章翻译为独立文章)
- [x] 文章点赞（全局计数，data/likes.json 持久化）
- [ ] 文章评论系统
- [ ] 阅读量统计
- [ ] 相关文章推荐
- [ ] 图片灯箱（mermaid 图已有缩放预览，正文图片没有）

## 不做什么

- ❌ 复杂的用户系统（登录/注册）
- ❌ 复杂的 CMS 管理后台
- ❌ 动态内容（评论实时推送）
- ❌ 广告系统
- ❌ 付费阅读

## 成功指标

1. **性能**：LCP < 2.5s，CLS < 0.1
2. **SEO**：Google 索引收录率 100%
3. **可维护性**：ESLint/TypeScript 0 错误
4. **可访问性**： Lighthouse Accessibility > 90
