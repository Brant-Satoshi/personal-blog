# 产品需求文档 (PRD)

## 项目概述

一个高性能、可维护的个人博客系统，用于分享技术文章和个人见解。

## 目标用户

- **主要用户**：技术社区读者、潜在雇主
- **次要用户**：开发者、同行博主

## 核心页面

| 页面 | 路径 | 描述 |
|------|------|------|
| 首页 | `/` | 文章列表、个人简介 |
| 文章详情 | `/[slug]` | 单篇文章展示 |
| 归档 | `/archive` | 按时间/分类归档 |
| 关于 | `/about` | 个人介绍、联系方式 |

## 功能清单

### MVP (第一期)

- [ ] Markdown 文章渲染
- [ ] 文章列表分页
- [ ] 文章标签/分类
- [ ] 响应式布局
- [ ] SEO 基础（title、description）
- [ ] RSS 订阅
- [ ] 深色模式

### 后续迭代

- [ ] 搜索功能
- [ ] 文章评论系统
- [ ] 阅读量统计
- [ ] 文章目录 (Table of Contents)
- [ ] 相关文章推荐
- [ ] 国际化 (i18n)
- [ ] 图片灯箱

## 不做什么

- ❌ 复杂的用户系统（登录/注册）
- ❌ 复杂的 CMS 管理后台
- ❌ 动态内容（评论实时推送）
- ❌ 广告系统
- ❌ 付费阅读

## 成功指标

1. **性能**：LCP < 2.5s，CLS < 0.1
2. **SEO**：Google 索引收录率 100%
3. **可维护性**：ESLint/TypeScript 0 错误
4. **可访问性**： Lighthouse Accessibility > 90
