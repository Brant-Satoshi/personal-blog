# 常用指令模板

## 生成新页面

```
在 app/[slug] 下创建文章详情页，需要：
1. 从 content/posts 读取 Markdown 文件
2. 使用 gray-matter 解析 frontmatter
3. 渲染 Markdown 内容
4. 添加 SEO 元信息
```

## 添加新功能

```
请为博客添加 [功能描述]，需要：
1. 在合适位置创建组件
2. 添加必要的类型定义
3. 编写样式（使用 Tailwind）
4. 确保响应式兼容
```

## 代码重构

```
请重构 [组件/函数名]：
1. 提取可复用的逻辑到 Hook
2. 简化条件判断
3. 优化类型定义
4. 保持功能不变
```

## 修复 Bug

```
[描述问题]：发生时点击 [按钮/链接]，[期望行为] 但实际 [实际行为]
请定位问题并修复
```
